# 艾瑟兰战役 — SillyTavern 扩展（三模式合集）

> 仓库：https://github.com/four-nine49/zhanyi
> 一句话：**正文 AI 讲故事，脚本自动算账。** 战役数值（算力/时钟/物品/人物）全程脚本结算，AI 只管叙事。

---

## 这是什么

给 SillyTavern（酒馆）写的扩展插件。**本发行版面板锁定为「艾瑟兰战役」模式**——悬浮窗内只提供战役页面与通用工具页；
另外两条业务线（渐变带 · 自由回路 / 剑与汽水）的代码仍保留在仓库里，只是界面隐藏、不可切换（需放开时改
`src/ui/app.ts` 顶部的 `锁定模式` 常量即可）。

| 模式 | 状态 |
|---|---|
| **艾瑟兰战役** | 本仓库主发行线。第一卷「维尔伦沦陷沙盘」：算力推演 / 双时钟压力 / 九人建档 / 物品四类，数据AI 增量结算 |
| 渐变带 · 自由回路 | 代码保留、面板隐藏（科幻魔法跑团：回路 / 施法 / 过载 / 双桌工作台） |
| 剑与汽水 | 代码保留、面板隐藏（角色卡专用向导式开局） |

## 运行原理（为什么数字不会乱）

页面上有三个东西在协作，靠**酒馆聊天变量**通信：

```
① 扩展后台（常驻，含纯函数引擎）← 你只看到它的悬浮球 🎬
     监听每条 AI 回复：调 数据AI 把正文翻译成"增量变更包"
     → 契约校验 → 纯函数结算 → 结果写回聊天变量
② 开局面板（注入楼层的 HTML）   ← 建档用
③ 状态栏（注入楼层的 HTML）     ← 只读存档渲染，不写数据
```

**铁律：数字只被脚本改。** 正文 AI 不接触公式，精算全部在本地引擎完成，所以正文怎么写，数值都不会飘。

## 安装（二选一，勿同时启用）

前提：先装好 **TavernHelper（酒馆助手）** 扩展并启用。

| 形态 | 方法 | 更新方式 |
|---|---|---|
| **扩展版** | 酒馆 → 扩展管理器 → 从 URL 安装：`https://github.com/four-nine49/zhanyi` | 酒馆启动时自动拉取 |
| **脚本版** | 酒馆助手 → 脚本库 → 导入 `releases/酒馆助手脚本-战役.json` 并启用 | 自动（从 jsDelivr CDN 按最新 tag 拉取） |

⚠️ 两种不要同时启用，加载器会互相拦截并提示。

## 艾瑟兰战役 · 玩起来（四步）

**第 0 步 · 导入两条正则**（改过 HTML 后需要重导）

酒馆「正则」页导入 `json/` 下的现成包：

| 查找标记 | 导入文件 | 干什么 |
|---|---|---|
| `<艾瑟兰开局/>` | `json/regex-艾瑟兰开局.json` | 开局面板入口 |
| `<StatusPlaceHolderImpl/>` | `json/regex-艾瑟兰状态栏.json` | 楼末状态栏 |

> ⚠️ 状态栏的查找标记与渐变带状态栏同款：**同一聊天只导入一个状态栏正则**（玩战役就导战役的）。

**第 1 步 · 开局**

「战役」页点「注入开局面板到最新楼」→ 楼层里出现开局面板：

- **性别**：男 / 女（纯叙事）
- **四维属性**：40 点自由分配，单项 1–13（本卷天花板 13），实时显示剩余点数与标尺提示
- **开场白**：可编辑文本框，确认后写入第 0 楼

点「确认开局」→ 存档写入 chat 变量 `艾瑟兰` → 开场白落第 0 楼 → 快照同步 → 开聊。

**第 2 步 · 开玩**

正常与 AI 对话即可。每回合数据AI 把正文变化翻译成增量变更包（只报变化：时间/时钟/推演/属性/物品/生物…），
脚本契约校验后结算并写档。「战役」页可手动结算、同步快照、重置存档。

**第 3 步 · 看状态栏**

楼末自动渲染：时刻 / 位置 / 世界状态徽章 · 陷落度 6 格 + 肃清 4 格时钟（含阶段名）· 算力条与累计消耗刻度 ·
主角属性（含临时加成）与装备技能 · 物品四类 · 已遇见人物（同伴/敌对分组，死亡灰显，未遇见不显示）。

## 战役数值速览（全部由脚本结算）

- **算力**：每小时自动 +10（上限 = 20×智力）；推演按档一次性扣费（档1–5 = 10/25/50/150/400），
  瞬时完成、无门槛、只产图纸不产实物；累计消耗 100 触发【异象】、250 触发【裂隙】
- **双时钟**：陷落度 0–6（脚本每满 240 分钟自动 +1，战斗/爆破另由 AI 申报，不封顶）；
  肃清进度 0–3（纯 AI 申报）
- **时间**：存档存格里高利历时刻，AI 每回合只报「当前时刻」，Δt 由脚本算（±720 分钟防呆）
- **四维**：基础值 5–13；临时加成（药剂/战歌）由 AI 申报时带持续分钟，脚本自动倒计时到期
- **物品**：装备（带槽位）/ 消耗品 / 材料 / 特殊，四类；装备系统只有主角与爱丽丝有
- **人物**：九人建档（爱丽丝/诺拉/瓦尔特/提尔雅/维克托/马利基/虚空暴食魔/异界幼体），
  敌对立场**绝不可招募**；死亡不删条目，状态栏灰显

## 渐变带 · 自由回路 / 剑与汽水

两个既有模式完整保留：

- **渐变带**：正则包为 `json/regex-开局.json`（`<渐变带开局/>`）与
  `json/regex-状态栏.json` / `regex-状态栏-手机.json`（`<StatusPlaceHolderImpl/>`）
- **剑与汽水**：走「表格数据 / 表结构」页与角色卡专用开局向导

两者的技术细节见 `docs/具体介绍.md`；AI 修改指南见 `AGENTS.md`。

## 开发者

```bash
pnpm install --ignore-workspace   # 首次
node build.mjs                    # 产 dist/index.js + index.css + 各 HTML（含艾瑟兰状态栏/开局）
node node_modules/typescript/bin/tsc --noEmit   # 类型检查（须 0 错误）
node smoke.mjs                    # 冒烟（init/destroy）
node scripts/test-aiselan.mjs           # 战役引擎 42 项断言
node scripts/test-aiselan-statusbar.mjs # 状态栏渲染 25 项断言
node package-loader.mjs           # 生成 releases/酒馆助手脚本-战役.json（23 项自检）
node scripts/gen-aiselan-regex.mjs    # 由 dist 生成两条战役正则包
node scripts/gen-aiselan-previews.mjs # 生成 美术预览/ 两个本地预览页（免酒馆）
```

> 图片（如状态栏地图）放 `src/aiselan/assets/img/`，HTML 里用 IMG 占位符，`node build.mjs` 会**构建期内联成 data URI**（不联网）；换图只需替换同名文件后重建。

## 常见问题

| 现象 | 解决 |
|---|---|
| 状态栏不显示 | 检查是否导入了对应正则（战役 → `json/regex-艾瑟兰状态栏.json`），且 AI 回复末尾有 `<StatusPlaceHolderImpl/>` |
| 开局面板不显示 | 检查是否导入 `json/regex-艾瑟兰开局.json`，并在「战役」页点过「注入开局面板到最新楼」 |
| 提示"请勿同时启用扩展版和脚本版" | 二选一，禁用另一个 |
| 数值不对 | 以状态栏/存档为准；「战役」页可手动结算一次，看回合日志排查 |
| 脚本版拉不到产物 | 确认 jsDelivr 能访问 `gcore.jsdelivr.net/gh/four-nine49/zhanyi@<tag>`（新 tag 首次需等 CDN 缓存） |
