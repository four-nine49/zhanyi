# 艾瑟兰战役 · 变量与数据AI 管线

> 面向：维护脚本的人、接手改动的 AI、想知道"数字到底存在哪、谁在改"的玩家。
> 本文是**实现说明书**：讲清每一份数据存在哪、谁读谁写、数据AI 每回合到底收到什么、错误怎么兜。
> 设计意图（为什么这么设计）见战役设计目录里的《变量设计.md》；本文以**代码现状**为准（v1.0.4）。

---

## 0. 一句话

存档放在酒馆聊天变量 `艾瑟兰` 里，是**唯一事实源**；每回合由脚本把正文交给"数据AI"翻译成一份**增量变更包**，脚本校验后结算写回存档，再同步一份快照到楼层变量，供状态栏（以及将来的 EJS 世界书条目）读取。

**铁律：数字只被脚本改。** 正文 AI 与数据AI 都不做算术、不直接改存档。

## 1. 五份数据，别搞混

| 存在哪 | 内容 | 谁读 | 谁写 | 生命周期 |
|---|---|---|---|---|
| chat 变量 **`艾瑟兰`** | 完整存档（本文第 2 节全部字段） | 脚本（`core/store.ts`） | 脚本 | 换聊天自动隔离；「重置存档」手动清 |
| message 变量 **`stat_data.艾瑟兰`** | 存档快照，**剥掉 `时刻.累计分钟`** | 状态栏 HTML、（待做）EJS 世界书条目 | 脚本 `syncSnapshot()` | 每回合同步到最新楼 + 开局时写第 0 楼 |
| chat 变量 **`艾瑟兰日志`** | 上一回合的结算日志：动作行、被丢弃的条目、错误 | 「战役」页展示 | 脚本 | 每回合覆盖 |
| extensionSettings **`艾瑟兰战役`** | 设置：自动结算开关、状态栏标记、数据AI 频率、API 配置、提示词分段 | 「战役」页 /「战役·提示词」页 /「API」页 | 面板 | 跟酒馆设置走 |
| 内存（不落盘） | 忙碌标志（防重入）、回合计数 | 调度器 | 调度器 | 关页面即失 |

> ⚠️ 状态栏与 EJS 条目**只读快照，永不写档**；玩家操作（确认推演等）走 chat 变量通道（手操功能尚未实现）。

## 2. 变量总表

### 2.1 时刻

| 字段 | 类型 | 默认 | 谁改 | 说明 |
|---|---|---|---|---|
| `时刻.当前时刻` | 字符串 `"1042年11月29日 14:20"` | 开局值 | 数据AI（唯一必填字段） | 格里高利历；脚本按它与存档中的时刻算 Δt |
| `时刻.累计分钟` | 整数 | 0 | 脚本 | **内部账本**：算力恢复、临时加成倒计时、陷落度自动推进都按它算；快照里被剥掉，AI 永不可见 |

Δt 防呆：`< 0` 按 0（AI 报了个更早的时刻）；`> 720` 封顶 720 分钟（防 AI 一觉睡三天）。

### 2.2 位置

| 字段 | 类型 | 默认 | 说明 |
|---|---|---|---|
| `位置.当前` | 自由文本 | `"审判广场"` | 具体地点，如"灰石集市·工坊区通风管道" |
| `位置.区域` | 枚举 `下层/中层/上层/城外` | `下层` | 与沙盘四层结构对齐；枚举校验，越界丢弃 |

### 2.3 时钟

| 字段 | 范围 | 推进方式 | 说明 |
|---|---|---|---|
| `时钟.维尔伦陷落度` | 0–6 | **脚本**每累计满 240 分钟自动 +1；数据AI 另可申报事件增量 | 两者同回合叠加，不封顶（钳到 6） |
| `时钟.教会肃清进度` | 0–3 | 纯数据AI 申报 | 只增不减（契约层 min(1)，负数进不来） |

### 2.4 算力

| 字段 | 默认 | 说明 |
|---|---|---|
| `算力.当前算力` | 0 | 存量；每回合 `+Δt×速率/60`，封顶 `20×基础智力`，溢出作废 |
| `算力.速率` | 10 | 每小时恢复点数；第一卷恒定，留作后续卷的修改口 |
| `算力.累计消耗` | 0 | 只增不减；≥100 世界【异象】、≥250 世界【裂隙】 |
| `算力.推演记录` | `[]` | `[{名称, 档, 实付算力, 时刻}]`，成交时追加，供状态栏/卷末回顾 |

> **算力不给数据AI看**（它不做算术，推演只报名称与档位，费用与阈值一律脚本裁决）。算力是给玩家看的资源：正文AI 通过 EJS 注入看到"当前算力 45/220"，从而能自己编出"算力不足"的回应。

### 2.5 物品（一张列表，全档一份）

| 字段 | 说明 |
|---|---|
| `名称` | 唯一标识（增删按名称+持有者） |
| `类型` | `装备` / `消耗品` / `材料` / `特殊` |
| `持有者` | 默认 `主角`；可写生物名（如爱丽丝身上的种子） |
| `数量` | 装备为 1；消耗品/材料/特殊归 0 自动删条目 |
| `描述` | 自由文本 |
| `槽` | **仅装备**有：`武器` / `副手` / `护甲` / `饰品` |

装备槽引用物品名：只有**主角**与**爱丽丝**有装备槽（`主角.装备` / `生物.爱丽丝.装备`），槽位与物品的 `槽` 必须匹配、持有者必须一致，否则该条丢弃。

### 2.6 主角

| 字段 | 类型/范围 | 默认 | 谁改 | 说明 |
|---|---|---|---|---|
| `性别` | 枚举 `男/女` | 男 | 开局面板 | 纯叙事，第一卷无数值影响 |
| `属性` | 力/敏/体/智 各 1–13 | 8/8/8/11 | 数据AI（增量，单次 ±2） | 本卷天花板 13（NPC 不设 13 上限，钳 1–23） |
| `临时加成` | `[{属性,值,剩余分钟,来源}]` | `[]` | 数据AI 申报；**脚本**按 Δt 倒计时，到期自动删 | 同一属性多条叠加（战歌+药剂=力+3） |
| `状态` | 自由文本 | `""` | ⚠️ **当前无申报口子**（见第 6 节缺口） | 例："轻伤""中毒(每半小时判定)" |
| `技能` | `[{名称,等阶,描述}]`，等阶 入门/熟练/精通/大师 | `[]` | 数据AI 新增/提升（阶梯+1）/移除 | 重名不重复添加；已是大师再提升→丢弃该条 |
| `装备` | `{武器,副手,护甲,饰品}` 槽→物品名或 null | 全 null | 数据AI 装备变更 | 校验通过才写入 |
| `精练师等级` | 枚举 无/低级/中级/高级 | 无 | ⚠️ 契约有字段、**提示词暂无规则**（见第 6 节） | 只升不降 |
| `已解锁知识库` | 字符串数组 | `["地球"]` | 脚本（第一卷锁死） | 契约不开口子，AI 改不了 |

### 2.7 生物（八名建档对象）

| 字段 | 说明 |
|---|---|
| `类型` | `核心`（爱丽丝）/ `重要`（其余 NPC）/ `生物`（两个 boss）——**契约不开变更口子** |
| `立场` | `同伴` / `敌对` / `中立`（预留）——**契约不开变更口子**；敌对绝不可招募 |
| `已遇见` | 布尔，只能 false→true；状态栏/战役页只渲染已遇见的 |
| `状态` | 自由文本："在队""留守在协会""死亡"；死亡不删条目，显示灰显 |
| `和主角的关系` | 枚举 `路人/相识/熟人/恋人/灵魂的另一半`，默认 `路人`；仅**同伴**立场有显示意义；settle 做白名单校验 |
| `属性` | 四维 1–23；数据AI 可增量申报（单次 ±2） |
| `临时加成` | 同主角，脚本按 Δt 倒计时 |
| `技能` | 同主角 |
| `装备` | **仅爱丽丝有**（核心人物） |

### 2.8 派生量（不存储，用时现算）

| 派生量 | 公式 | 用在哪 |
|---|---|---|
| 算力上限 | `20 × 基础智力`（临时加成的智力不计入） | 存算封顶、状态栏显示 |
| 生效属性 | 基础值 + 同属性临时加成求和 | 状态栏与数据AI 摘要显示"力9"而不是"力8+1" |
| 世界状态 | 累计消耗 <100 微澜 / ≥100 异象 / ≥250 裂隙 | 状态栏徽章、沙盘后果表 |
| 陷落度阶段名 | 0–6 格 → 风暴眼/混乱期/沦陷期/收束期/终局 | 状态栏与摘要的括号文案 |

### 2.9 刻意不入档的东西

马利基真相、暗金圣火目击、逃生路线、卷末带走的人/物资/信息——这些交给正文AI 与记忆插件，脚本不追踪（也就不做路线相关的自动判定，例如"走圣堂裂隙道不推肃清钟"由数据AI 按提示词遵守）。

## 3. 数据AI 管线

### 3.1 回合时序

```
酒馆产生新 AI 回复（type ∈ normal/regenerate/continue/swipe）
        │
        ├─ 未开局（无 `艾瑟兰` 存档）→ 完全静默，不抢渐变带/开局框架的活
        ├─ busy 防重入；按「数据AI 频率」每 N 条跑一次（未跑则只补楼末标记）
        ▼
  ① loadGame()                     读 chat 变量 `艾瑟兰`（zod 校验，坏档忽略）
  ② runDataAI(game)
        ├─ 拼提示词：设置里的分段 + {{状态}}（serialize数据AI）+ {{正文}}（分层正文）
        ├─ callGenerate（json_schema 结构化输出；API 走「API」页配置，默认跟随酒馆）
        ├─ 抽取 JSON（容忍 ```json 包裹与前后废话）
        └─ zod 契约校验 → 通过则给出"变更包"
  ③ settle(game, 变更包)            纯函数，严格按 11 步顺序结算（见 3.4）
  ④ saveGame(新存档)                写回 chat 变量
  ⑤ syncSnapshot()                 剥 `时刻.累计分钟` → 写最新楼 stat_data.艾瑟兰
  ⑥ 写 `艾瑟兰日志`（动作行/丢弃/错误）
  ⑦ 若开关「状态栏标记」开 → 楼末补 `<StatusPlaceHolderImpl/>`（幂等）
```

手动入口：「战役」页的「手动结算一次」（走同一 runTurn）、「重置存档」、「注入开局面板到最新楼」。

### 3.2 数据AI 实际收到的三样东西

**① 提示词（分段可在「战役·提示词」页编辑，默认 5 段）**

| 段 | role | 内容 |
|---|---|---|
| 1 | system | 任务与 13 条铁律（不做算术/只报变化/禁止凭空造物/时刻格式/推演档位/时钟条件/属性条件/临时加成/生物白名单/关系/异界幼体/事件范围铁律） |
| 2 | system | 【当前状态】＝ `serialize数据AI()` 的输出（见下） |
| 3 | system | 【最近正文】＝ 分层正文：**前文背景**（上一轮及更早，只读因果）＋ **本轮待结算正文**（最新一轮，唯一提取源） |
| 4 | system | 【输出格式示例】＝ 一两个 JSON 形状示例 |
| 5 | user | 收尾指令："只写发生变化的字段" |

每段发出前会做酒馆宏替换（`{{user}}` 等）。

**② 状态摘要（`src/aiselan/pipeline/serialize.ts`）**

原则：**只给"AI 要靠它才能做出正确申报"的信息**。样例：

```
【当前状态】
当前时刻：1042年11月29日 22:40
位置：中层 · 灰石集市·工坊区通风管道
陷落度：2/6（混乱期）｜肃清进度：1/3
主角：力9 敏9 体9 智11，临时：力量+1(战歌,剩120分)
主角状态：轻伤
主角技能：剑术(熟练)
主角装备：武器:精钢短剑
精练师等级：无｜已解锁知识库：地球
物品：精钢短剑×1(装备/武器)、治疗药剂×1(消耗品)、硝石×3(材料)、燃烧瓶图纸×1(特殊)
已遇见人物：爱丽丝(同伴,在队,关系:相识)、诺拉(同伴,留守在通风管道,关系:相识)、维克托(敌对,在广场清点幸存者)
```

刻意**不发**：算力（含上限/速率/累计消耗/世界状态）——AI 不做算术；未遇见的人物（避免它乱报）；不入档的叙事状态。

查看器：`node scripts/show-data-ai-prompt.mjs`（用真实代码拼装，占位符填假数据，随时可导出对照）。

**③ json_schema（结构化输出约束）**

顶层属性：`当前时刻`（必填）、`位置`、`时钟`、`推演`、`属性`、`临时加成新增`、`临时加成移除`、`精练师等级`、`物品新增`、`物品移除`、`物品数量`、`装备变更`、`技能新增`、`技能提升`、`技能移除`、`生物`。除 `当前时刻` 外**全部可选**，从 schema 层面逼 AI"只报变化"。

绝大多数回合只需要一行 `{"当前时刻": "..."}`。

### 3.4 结算顺序（`pipeline/settle.ts`，严格按序）

| # | 步骤 | 规则与钳制 |
|---|---|---|
| 1 | **时间结算** | Δt 防呆（<0→0，>720→720）→ 算力 `+Δt×速率/60` 且封顶 `20×智力` → 临时加成逐条扣 `剩余分钟`（≤0 删）→ 累计分钟累加，每满 240 分钟陷落度 +1 |
| 2 | 位置 | 区域枚举校验；当前自由文本覆盖 |
| 3 | 时钟申报 | 只接受正增量、只增不减，钳 0–6 / 0–3 |
| 4 | 推演 | 按档定价 10/25/50/150/400；算力够→扣费+累计消耗+写推演记录；**不够→只丢这一条** |
| 5 | 属性 | 每项单次 ±2；主角钳 5–13（实现为 1–13，本卷天花板 13），NPC 钳 1–23 |
| 6 | 临时加成 | 新增必须含 属性/值/持续分钟/来源；移除按来源名 |
| 7 | 物品/装备 | 新增/移除/数量（归 0 删条目）；装备变更校验存在性/类型/槽/持有者 |
| 8 | 技能 | 新增（重名跳过）/提升（阶梯+1，已是大师丢弃）/移除 |
| 9 | 精练师等级 | 枚举校验，只升不降 |
| 10 | 生物 | 不在建档列表→丢弃；`已遇见` 只能 false→true；`状态` 自由文本；`和主角的关系` 白名单校验；属性增量 ±2 |
| 11 | 写档 + 快照 + 日志 | 见 3.1 的 ④⑤⑥ |

### 3.5 容错策略（重要）

| 情况 | 处理 |
|---|---|
| API 报错 / 返回空 | 记错误到日志，本回合不结算（存档不动） |
| 抽不出 JSON | 同上（整包丢弃） |
| JSON 能抽出但**整包不符合契约**（如时刻格式错） | 整包丢弃，日志记录前三条 zod 报错 |
| **单条语义非法**（未建档生物、关系值不在白名单、技能不存在、装备槽不匹配、推演算力不足、区域枚举越界） | **只丢该条**，其余照常落地，日志记"丢弃"行 |
| AI 报负数时钟 / 非法档位 | 丢弃该条 |
| AI 报了契约外的新字段 | **静默忽略**（zod 默认行为，不报错） |

### 3.6 快照与消费侧

- `syncSnapshot()` 深拷贝存档 → 删 `时刻.累计分钟` → 写最新楼 `stat_data.艾瑟兰`
- 状态栏 HTML 读快照时按 **当前楼 → -1 → -2 → -3** 回退查找，再回退读 chat 变量（只读）
- 状态栏显示：时刻/位置/世界状态徽章、陷落度 6 格与肃清 4 格（含阶段名）、算力条与累计消耗刻度、主角属性（含临时加成）与装备技能、物品四类、已遇见人物（同伴/敌对分组，死亡灰显，同伴显示关系）
- **EJS 世界书条目（待做）**：读快照翻译成人话注入正文AI（正文AI 只看描述、不看公式，且算力对它是可见的）

## 4. 数据AI 提示词的 13 条铁律速查

| # | 规则 | 触发条件 | 对应字段 |
|---|---|---|---|
| 1 | 不做任何算术 | 永远 | —（算力恢复/扣费/时钟自动推进/加成倒计时全归脚本） |
| 2 | 只报变化 | 永远 | 全部 |
| 3 | 不凭空造物 | 永远 | `物品新增` 必须有正文依据 |
| 4 | 只输出 JSON | 永远 | —（字段以 schema 为准） |
| 5 | 时刻格式与推断 | 每回合必填 | `当前时刻` |
| 6 | 推演 | 玩家明确指令系统推演 | `推演{名称,档}` |
| 7 | 时钟 | 大规模战斗/爆破（陷落度）；教会面前用系统产物或异术、正面冲突、目击者增加（肃清） | `时钟` |
| 8 | 属性 | 越级击杀（力/敏+1）、濒死生还（体+1）、破解真相/关键推演/打通节点（智+1） | `属性` |
| 9 | 临时加成 | 药剂、战歌等临时效果与被打断 | `临时加成新增/移除` |
| 10 | 生物 | 初遇、状态变化 | `生物{已遇见,状态}` |
| 11 | 关系 | 同伴立场、有实质关系进展 | `生物{和主角的关系}` |
| 12 | 异界幼体 | 陷落度到 5/6 | `生物{异界幼体.状态}` |
| 13 | 事件范围铁律 | 永远（防重复结算） | 全部（只从前文背景之外的最新一轮提取） |

## 6. 已知缺口（诚实列出，待修）

| # | 缺口 | 影响 |
|---|---|---|
| 1 | **`主角.状态` 没有契约/提示词口子** | 状态栏会显示"主角状态：轻伤"，但脚本与 AI 都没有途径改它——主角状态目前是死的 |
| 2 | **`精练师等级`、`装备变更` 无提示词规则** | 契约与 json_schema 都有字段，但 AI 不知道何时申报，等于白设 |
| 3 | **铁律 4 文案与实现不符** | 文案说"额外字段会被整包拒绝"，实际是静默忽略（zod 默认行为） |
| 4 | **铁律 8 的"打通节点"是元概念** | "节点 A~F"只存在于沙盘设计文档，数据AI 看不到，该条件实际失效 |
| 5 | **推演被驳回后无反馈** | AI 不知道算力不够，可能下一回合重复报同一次推演（重复驳回无害，但浪费） |
| 6 | **EJS 状态注入条目未做** | 正文AI 目前拿不到"当前算力/时钟/人物"的系统化描述，只能靠聊天上下文 |
| 7 | **状态栏手操未做** | 玩家不能在状态栏上直接确认推演/装槽，只能靠在正文里下指令 |

## 7. 一句话总结数据流

正文（AI 写的故事） → **数据AI**（翻译成"变了什么"） → **契约**（zod 校验形状） → **settle**（纯函数按 11 步结算，数字全部脚本算） → **存档**（chat 变量 `艾瑟兰`） → **快照**（stat_data.艾瑟兰，剥内部账本） → **状态栏 / EJS**（只读展示）。
